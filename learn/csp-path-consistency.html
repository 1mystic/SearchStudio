Week 11 · Constraint processing

Path consistency (PC, i-consistency)

Run it step by step

Arc consistency looks at one constraint at a time. Path consistency looks at a path of two constraints through a third variable, which is the smallest way to notice that constraints interact.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

The network is i-consistent if every consistent assignment to any i − 1 variables can be extended to any i-th variable. Arc consistency is 2-consistency; path consistency is 3-consistency: every consistent pair (X = a, Y = b) can be extended to every third variable Z. Enforcing it deletes pairs from the relation R(X,Y), possibly making a new implicit constraint between variables that had none.

02Pseudocode

PC-1:
    R(X,Y) ← allowed pairs of the constraint, or all pairs if X and Y are unconstrained
    repeat
        for each triangle (X, Z, Y)
            R(X,Y) ← R(X,Y) ∩ ( R(X,Z) ∘ R(Z,Y) )       # (a,b) needs a witness c in D(Z)
    until no relation changed
    if some R(X,Y) is empty: no solution

03Line by line

pick a triangle X, Z, YOnly two constraints are used at a time: R(X,Z) and R(Z,Y).
compose R(X,Z) ∘ R(Z,Y)All pairs (a, b) for which some c fits both.
intersect with R(X,Y)Pairs without a witness are deleted.
repeat until nothing changesA deletion can destroy the witness of another pair.
empty relationNo solution.

04Formulas and why they hold

R(X,Y) ← R(X,Y) ∩ { (a,b) : ∃ c ∈ D(Z), (a,c) ∈ R(X,Z) ∧ (c,b) ∈ R(Z,Y) }

keep a pair only if the third variable can be given a value that works with both

In any solution containing X = a, Y = b, the variable Z has some value c, and that value must satisfy both constraints, so pairs with no such c cannot be in a solution.

k-consistency: every consistent (k−1)-assignment extends to any k-th variable

k = 1 node, k = 2 arc, k = 3 path

Higher k reasons about bigger groups, at a higher cost; k = n gives a backtrack-free search.

05Why it works, and when it does not

Two colours on a triangle: each value has a partner on every edge, so arc consistency removes nothing, yet three mutually different variables with two values cannot exist. Path consistency empties a relation and proves it.

06Properties

completeno (filtering only)
optimaln/a
timeO(n³·d³) per sweep
spaceO(n²·d²)

07Traps

  • Try example 'Two colours on a triangle': run Arc consistency first (nothing is deleted), then this algorithm (a relation becomes empty). Path consistency is strictly stronger than arc consistency, and also costlier.
  • Path consistency prunes PAIRS (it changes constraints), not just values; domains shrink only afterwards, when arc consistency is run on the tightened relations (done in the last step).
  • It can add constraints between variables that had none: unconstrained pairs start as 'all pairs allowed'.
  • The i-consistency hierarchy (strong i-consistency for i = n gives backtrack-free search) is shown as background; only the 3-consistency algorithm is traced. The remark on strong k-consistency is **supplementary**.
