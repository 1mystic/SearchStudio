Week 11 · Constraint processing

Backtracking

Run it step by step

A constraint satisfaction problem has variables, each with a domain of values, and constraints saying which combinations are allowed. A solution assigns every variable a value from its domain so that every constraint holds. Backtracking is depth-first search over partial assignments.

01Definition

Assign variables in a fixed order. Try each value; keep it if it is consistent with the earlier assignments and continue; if no value works, return to the previous variable and try its next value.

02Pseudocode

Backtrack(assignment, i):
    if i > n: return assignment
    for each value a in D(Xᵢ)
        if a is consistent with every assigned neighbour of Xᵢ
            result ← Backtrack(assignment + {Xᵢ = a}, i + 1)
            if result ≠ failure: return result
    return failure                          # go back to Xᵢ₋₁

04Formulas and why they hold

search tree size ≤ d + d² + … + dⁿ

up to dⁿ complete assignments

Each level multiplies the branches by the domain size.

05Why it works, and when it does not

Complete and simple, but it discovers failures late. Look-ahead (forward checking) and consistency (arc consistency) detect them earlier.

07Traps

  • Count every value tried as a node.
  • Backtracking returns to the most recent variable, even if it is not the cause of the failure.
