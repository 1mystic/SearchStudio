Breadth First Heuristic Search (BFHS)

Run it step by step

A* remembers every node it has expanded. Breadth First Heuristic Search borrows breadth-first search's layering: it knows that a node can only be regenerated from a neighbouring layer, so older layers can be thrown away. An upper bound U on f keeps the layers narrow. **Supplementary:** BFHS is from Zhou and Hansen's work on memory-bounded graph search; it is beyond the lecture slides.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Layer k holds the nodes reached with k moves. Expand layer k completely to build layer k+1. A child is discarded if f = g + h > U. Duplicate detection looks only at the current layer, the previous layer and the layer being built, which is enough on undirected graphs and means all earlier layers can be deleted. When a goal is picked with g < U, U shrinks to g. The search ends when a layer is empty.

02Pseudocode

U ← cost of a quick solution (greedy) or a given bound
layer0 ← [S]
while the current layer is not empty
    for each node N in the layer (least f first)
        if GoalTest(N) and g(N) < U: remember N, U ← g(N)
        else for each child C:  if g(C) + h(C) > U: discard
                                 elif C is already in the current, previous or next layer with g ≤ g(C): skip
                                 else put C in the next layer
    delete the layer before the previous one          # keep only the boundary
    move to the next layer
return the best goal found (or the quick solution)

03Line by line

U ← greedy costA real solution gives a valid bound.
expand the whole layerUnlike A*, nodes are not picked one at a time across layers.
if f(C) > U: discardWith admissible h such a node cannot be on a cheaper path.
delete the layer before the previous oneThe boundary of two layers is enough for duplicate detection.

04Formulas and why they hold

CLOSED = layers k and k−1

only the boundary is stored

Every neighbour of a layer-k node is in layer k−1, k or k+1 (in a graph of unit moves), so older layers can never be regenerated through duplicate detection.

discard C when g(C) + h(C) > U

bound pruning

It keeps the layers narrow and, with h ≤ h*, never discards the optimal path when U ≥ C*.

05Why it works, and when it does not

BFHS stores far fewer expanded nodes than A* on graphs whose layers are narrow compared with the whole explored region: on the 4×5 grid its peak CLOSED is 8 against A*'s 19. It pays with expanding every node with f ≤ U, even ones A* would never reach.

06Properties

completeyes if U ≥ C*

07Traps

  • Costs are compared across layers, so a node can be reached in a later layer with a lower g; this tracer keeps the cheaper copy only when it is still in a retained layer.
  • A bad (large) U weakens the pruning but never breaks the answer.
  • In the original BFHS no parent pointers are kept, so only the cost is known; here parent links are kept just to print the path. Divide and Conquer BFHS shows how to recover it without them.
