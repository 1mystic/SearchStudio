DFS on a state space

Run it step by step

Depth First Search follows one line of moves as far as it goes, and only when it hits a dead end (or a state it has seen) does it return to the most recent choice. On a state space with MoveGen in code this finds a solution fast, but not necessarily a short one.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

The same node pairs (state, parent, depth) and the same OPEN/CLOSED lists as BFS, but OPEN is a stack: the children of the picked node are put at the front in MoveGen order, so the first child is picked next. The goal test is on picking. A child already on OPEN or CLOSED is not added again. An optional depth bound stops the dive.

02Pseudocode

OPEN ← [(S, nil, 0)];  CLOSED ← [ ]
while OPEN not empty
    (N, parent, d) ← head(OPEN);  remove it
    if GoalTest(N): return the path via parent pointers
    CLOSED ← (N, parent, d) : CLOSED
    if depth bound reached: continue
    children ← MoveGen(N) minus states on OPEN or CLOSED
    OPEN ← [(C, N, d+1) for C in children] ++ OPEN     # prepend = stack
return failure

03Line by line

OPEN ← [(S, nil, 0)]
(N, parent, d) ← head(OPEN)Newest pair first (stack).
if GoalTest(N): return pathTested on picking.
children ← MoveGen(N) minus seen statesGraph search: no repeats.

04Formulas and why they hold

solution depth ≥ shortest depth d

a goal is found, maybe deep

DFS commits to the first child each time, so the first goal it reaches lies on whatever branch it dived into.

05Why it works, and when it does not

On the water-jug problem DFS reaches a state with 4 litres but often by a longer pouring sequence than BFS. On the 8-puzzle without a bound it can wander through thousands of states, which is why the studio has an expansion cap and an optional depth bound.

06Properties

completeyes on a finite space with CLOSED
optimalno
timeO(b^m)
spacelinear on a tree; with CLOSED, all states seen

07Traps

  • DFS is not optimal: on example space-jug-seven (7 litres in some jug) BFS needs 5 pourings, DFS 9. Run both and compare the solution tables.
  • On the 8-puzzle DFS wanders: space-8-puzzle exhausts the 400-expansion cap without reaching a goal five moves away.
  • Without CLOSED, DFS can loop forever on a state space with cycles (pour back and forth). CLOSED fixes that.
  • With a depth bound and CLOSED, a state first reached by a deep path is closed and not retried by a shorter one, so the search can miss a solution within the bound (supplementary note).
  • The order of children is MoveGen's order; a different order sends the dive down another branch.
