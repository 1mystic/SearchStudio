Depth First Iterative Deepening

Run it step by step

Depth First Iterative Deepening runs DFS with a depth limit of 0, then 1, then 2, … It finds the same shallow path as BFS while using only DFS's memory.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Repeat depth-bounded DFS (DB-DFS) with an increasing bound until the goal is found. DB-DFS does not expand nodes at depth equal to the bound.

02Pseudocode

for bound ← 0, 1, 2, …
    result ← DB-DFS(S, bound)      # DFS that does not expand nodes at depth = bound
    if result ≠ failure: return result
    if no node was cut off by the bound: return failure

03Line by line

for bound ← 0, 1, 2, …
DB-DFS(S, bound)A full DFS that stops descending at the bound.
if found: returnThe first bound that works is the shallowest goal depth.

04Formulas and why they hold

N(DFID) ≈ N(BFS) · b/(b−1)

extra work is a small factor of BFS

Most nodes of a tree are on the last level, so repeating the upper levels is cheap.

05Why it works, and when it does not

Combines BFS's optimal depth with DFS's small memory; the repeated work is small for branching factors above 2.

06Properties

completeyes
optimalyes for unit costs
timeO(b^d)
spaceO(b·d)

07Traps

  • Count expansions over all rounds, not just the last.
  • With CLOSED checking, DB-DFS can miss a shallower route to a node seen earlier via a deeper path.
