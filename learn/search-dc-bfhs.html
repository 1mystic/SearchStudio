Week 6 · Graph search · space saving

Divide and Conquer BFHS (DC-BFHS)

Run it step by step

Deleting layers saves memory but loses the parent pointers needed to print the path. Divide and Conquer BFHS keeps one thing instead: the middle node of the best path. Each half is then a smaller search of the same kind. **Supplementary:** from Zhou and Hansen; the relay idea matches Divide and Conquer Frontier Search from the course. The beam-search version (DC beam search) is not implemented here.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Run BFHS to find the optimal cost C and the layer count L. Run it again with every node on layer ⌊L/2⌋ acting as a relay: its descendants carry the relay's name and its g. The goal's relay R splits the problem into S→R (cost g(R)) and R→T (cost C − g(R)). Solve each recursively; in the sub-searches the exact cost is the upper bound U and h = 0 (the original h aims at T, not R).

02Pseudocode

DC-BFHS(S, T, U):
    run BFHS from S to T with bound U, no parent pointers      # gives cost C and the number of layers L
    if L ≤ 1: return [S, T]
    run it again, each node at layer ⌊L/2⌋ becoming its own relay and passing it on to descendants
    R ← the relay of the best goal, with g(R)
    return DC-BFHS(S, R, g(R)) ++ DC-BFHS(R, T, C − g(R))      # drop the repeated R

03Line by line

BFHS S→T, no parentsGives the cost and the number of layers.
mark layer ⌊L/2⌋ nodes as relaysEvery descendant inherits its ancestor's relay.
R ← relay of the goalA node halfway along an optimal path.
solve S→R and R→TExact costs are known, so U is exact in the halves.

04Formulas and why they hold

C = g(R) + cost(R→T)

an optimal path through R splits into two optimal halves

Each half of an optimal path is itself optimal, so solving the halves and joining them gives an optimal whole.

memory ≈ boundary layers of the largest sub-search

no pointers, no deep layers

The sub-searches run one at a time, so their memory is not added up.

05Why it works, and when it does not

Shows how to get the path from a search that keeps almost nothing: on the 4×5 grid the boundary CLOSED is at most 9 against A*'s 19. The cost is a second pass per level of recursion.

06Properties

completeyes if U ≥ C*
optimalyes with admissible h
time≈ 2 × BFHS
spaceboundary layers

07Traps

  • The relay must be recorded in the same run that finds the best goal; a different tie-break could give a different path and relay.
  • A sub-search uses h = 0, so it expands more nodes than the first run did.
  • The relay layer ⌊L/2⌋ is by number of moves, not by cost; on weighted graphs the halves can have unequal cost.
