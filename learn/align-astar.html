Week 6 · Sequence alignment

Sequence alignment (A*)

Run it step by step

Dynamic programming fills the whole table. A* treats alignment as a shortest-path search on the same lattice and, with a good heuristic, explores only the part of the table near the best alignment.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

States are lattice points (i,j); moves are diagonal, down and right with their costs. h(i,j) = gap × |(m−i) − (n−j)| because the remaining length difference must be covered by gaps.

02Pseudocode

start (0,0), goal (m,n)
moves: diagonal cost(aᵢ,bⱼ), down gap, right gap
h(i,j) = gap · |(m − i) − (n − j)|           # admissible: the length difference must be covered by gaps
run A*: pick least f = g + h from OPEN; update cheaper paths; stop when (m,n) is picked

03Line by line

start (0,0), goal (m,n)
h = gap · |remaining length difference|Admissible and consistent.
A* with OPEN and CLOSEDStop when (m,n) is picked from OPEN.

04Formulas and why they hold

h(i,j) = gap · |(m − i) − (n − j)|

at least this many gaps are unavoidable

Each gap shortens the length difference by one, so this many gap moves remain in any completion: h never overestimates.

05Why it works, and when it does not

Optimal like dynamic programming, usually with fewer states: the more alike the sequences, the fewer lattice points A* has to expand, because the cheap diagonal path keeps f low and everything else waits on OPEN. With large sequences, frontier search and DCFS keep its memory small.

06Properties

completeyes
optimalyes
time≤ O(m·n·log(m·n))
space≤ O(m·n)

07Traps

  • A weak h (such as 0) makes A* behave like Dijkstra and expand most of the table. When both sequences have the same length h is 0 at the start, so the saving comes only from the cheap diagonal moves: compare 'ACGTTGCAAT vs ACGTAGCAAT, one substitution' (11 of 121 points) with 'ACGTAC vs TGCATG, unrelated' (19 of 49).
  • A* is only guaranteed to find the optimal cost, not a unique alignment: several alignments can tie, and the tie-break decides which one is shown.
