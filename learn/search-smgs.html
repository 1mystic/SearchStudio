Week 6 · Graph search · space saving

Smart Memory Graph Search (SMGS)

Run it step by step

A* keeps every expanded node in CLOSED for two reasons: to avoid regenerating it, and to read the path back. A node whose neighbours have all been expanded can no longer be regenerated, so the first reason is gone. The second still holds for nodes on the way to the frontier. SMGS deletes the rest. The name and the idea of a boundary and relay nodes follow the lecture material on space-saving search; the exact deletion rule below is this site's reading of it, so treat the details as **supplementary**.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Run A*. After each expansion classify every CLOSED node. Boundary: at least one neighbour has not been expanded yet, so it may still be regenerated. Interior: all neighbours are expanded. A relay node is an interior node that is an ancestor, through parent pointers, of an OPEN or boundary node. Delete interior nodes that are not relays. The path to the goal is read from the nodes that remain.

02Pseudocode

OPEN ← [(S, nil, 0)];  CLOSED ← empty
while OPEN not empty
    N ← node with least f;  remove it
    if GoalTest(N): return the path (follow parents through the kept nodes)
    move N to CLOSED;  generate children as in A*
    for each X in CLOSED:
        if every neighbour of X has been expanded:  X is interior
    live ← OPEN ∪ {CLOSED nodes that are not interior}      # the boundary
    relay ← interior nodes that are ancestors of a live node
    delete every interior node that is not a relay

03Line by line

N ← least f; goal test; expandExactly A*.
boundary: some neighbour not expandedMust stay, it could be regenerated.
interior: all neighbours expandedCan never be regenerated: candidate for deletion.
relay: interior but an ancestor of a live nodeKept so every live node's parent chain stays intact.

04Formulas and why they hold

|CLOSED| ≤ |boundary| + |relay|

only the edge of the expanded region plus the needed ancestors

Everything else is deleted, so on wide graphs CLOSED is a thin shell instead of a solid blob.

05Why it works, and when it does not

Saves CLOSED memory at no cost in nodes expanded (on the 4×5 grid it deletes 9 nodes and the peak CLOSED falls from 19 to 17; the saving grows with the size of the graph). The relay rule is conservative: it keeps whole parent chains. Divide and conquer methods (DCFS, DC-BFHS) cut even those.

06Properties

completeyes
optimalyes with admissible h
timesame as A*
spaceboundary + relay nodes

07Traps

  • If an h is inconsistent a node can be reopened with a better g; its deleted neighbours are simply regenerated as new nodes.
  • Savings depend on the graph: on a tree or a path nearly every node stays a boundary or relay node.
