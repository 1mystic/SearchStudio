Savings heuristic

Run it step by step

Imagine a delivery van that returns to the depot after every single delivery. The Savings heuristic starts there and asks: which two trips can I combine to save the most driving? It keeps combining trips until there is just one round trip.

01Definition

Choose a base (fulcrum) city b. For each pair of other cities compute the saving S(i,j) of visiting i and j on one trip instead of two. Process pairs from the largest saving down, linking i and j whenever both are still ends of different sub-tours.

02Pseudocode

for every pair i, j ≠ base:  S(i,j) ← C(base,i) + C(base,j) − C(i,j)
sort pairs by S, largest first (ties: alphabetical)
start with n−1 sub-tours base–x–base
for each pair (i,j) in that order
    if i and j are ends of different sub-tours: link i–j (merge)
    else: skip (same sub-tour, or an interior city)
return the single tour

03Line by line

S(i,j) ← C(b,i) + C(b,j) − C(i,j)For n cities there are (n−1)(n−2)/2 pairs.
sort pairs, largest saving firstTies change the result; the course breaks them alphabetically.
start with b–x–b for every xInitial cost = 2 × Σ C(b,x).
link i–j if both are ends of different sub-toursAn end city is one still adjacent to the base. Linking removes edges b–i and b–j and adds i–j.
otherwise skipSame sub-tour: would close a cycle. Interior city: already has two non-base neighbours.
return the single tourFinal cost = initial cost − Σ accepted savings.

04Formulas and why they hold

S(i,j) = C(b,i) + C(b,j) − C(i,j)

trip b→i→b plus b→j→b, minus going i→j directly

Merging two out-and-back trips replaces the two edges i–b and b–j with one edge i–j; the difference is the distance saved.

cost = 2·Σₓ C(b,x) − Σ accepted S(i,j)

start with all out-and-back trips, subtract each saving you used

Every merge removes exactly its saving from the total, which is a quick way to check your final tour cost.

05Why it works, and when it does not

Savings rewards pairs that are far from the base but close to each other, which avoids stranding remote cities. It is usually the best of the three constructive heuristics, but the result depends on the base city and on tie-breaking.

06Properties

completealways returns a tour
optimalno
timeO(n² log n)
spaceO(n²)

07Traps

  • The savings formula has a minus on C(i,j), not on the base distances.
  • A pair is refused if either city is interior, even if they are in different sub-tours.
  • Know which pairs merged and which did not: exams ask for the first three of each.
