Stochastic hill climbing (fixed T)

Run it step by step

Stochastic hill climbing keeps the idea of preferring uphill moves but replaces the hard rule 'only if better' by a probability. A better neighbour is accepted with probability above one half, a worse one with probability below one half, and the temperature T decides how sharp that preference is. T stays fixed; simulated annealing is the version that lowers it.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Choose a random neighbour X of N. Let ΔE = h(X) − h(N); for SAT we maximise h, so ΔE > 0 is an improvement. Accept X with probability P = 1/(1 + e^(−ΔE/T)); draw u uniformly in [0, 1) and move if u < P.

02Pseudocode

N ← start;  bestSeen ← N
repeat k times
    X ← random neighbour of N (flip a random bit)
    ΔE ← h(X) − h(N)                  # positive = improvement (we maximise h)
    P ← 1 / (1 + e^(−ΔE / T))
    if random u < P: N ← X
    if h(N) > h(bestSeen): bestSeen ← N
return bestSeen

04Formulas and why they hold

P = 1 / (1 + e^(−ΔE/T))

a sigmoid in ΔE/T

ΔE = 0 gives exactly ½; ΔE > 0 gives more than ½ and ΔE < 0 less than ½, approaching 1 and 0 as |ΔE|/T grows.

T → 0: hill climbing; T → ∞: random walk

the two extremes

Small T makes the sigmoid a step at ΔE = 0 (only improving moves); large T flattens it to ½ (a coin flip, i.e. random walk).

05Why it works, and when it does not

A worse neighbour can still be accepted, so the search can walk down off a local maximum such as 1000 (h 5) towards 1101 (h 6). Because T never falls, it keeps wandering even after it has found a good string, which is why we report bestSeen.

07Traps

  • With the sigmoid rule even an improving move can be rejected (P < 1 at finite T).
  • ΔE is h(new) − h(current) here: do not copy the TSP sign.
  • Fixed T is a compromise: too hot is a random walk (try T = 100), too cold is hill climbing (try T = 0.05). Annealing varies it.
