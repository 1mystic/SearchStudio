SAT as a CSP: backtracking with unit propagation (DPLL)

Run it step by step

The local-search methods of weeks 3 and 4 move between complete assignments and can only find solutions. Constraint processing instead builds an assignment variable by variable, so a dead end is detected as soon as one clause becomes impossible, and the search is complete: if no solution exists it says so. This page is the Davis–Putnam–Logemann–Loveland style of backtracking on a CNF formula, viewed as a CSP whose variables have the domain {T, F}.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

A clause is satisfied once some literal is true and empty (a conflict) once all its literals are false. A unit clause has exactly one unassigned literal and none true, so that literal must be true. A pure literal occurs with only one sign in the clauses not yet satisfied, so making it true cannot hurt. Backtrack on an empty clause; otherwise branch on the first unassigned variable (alphabetical order, as in the course), trying T before F.

02Pseudocode

DPLL(assignment):
    repeat
        if some clause has every literal false: return FAIL          # empty clause
        if every clause is satisfied: return assignment
        if a clause has exactly one unassigned literal and no true literal: assign it true    # unit propagation
        else if a variable occurs with one polarity only in the open clauses: assign it so    # pure literal
        else break
    X ← first unassigned variable
    for each value v in {T, F}
        result ← DPLL(assignment + {X = v})
        if result ≠ FAIL: return result
        undo X = v and everything it forced
    return FAIL

03Line by line

empty clause → FAILEvery literal of some clause is false under the partial assignment: no extension can satisfy it, so this branch is dead. This is the CSP 'domain wipe-out'.
all clauses satisfied → returnVariables still unassigned are free: any value works. The trace shows them as 0.
unit propagationA clause with one open literal forces it. This is the SAT form of forward checking: the choice made at a decision is propagated into the clauses at once. Lowest clause number first.
pure literalA variable whose open occurrences all have the same sign can be set to satisfy them all. **Supplementary**: pure-literal elimination is a standard DPLL rule, not in the course notes; the 'pure' parameter switches it off.
branch on X, value T then FA decision. The value order is a parameter; the variable is always the first unassigned one that still occurs in an open clause.
undo and try the next valueBacktracking: remove the decision and every assignment it forced, then try the other value. When both fail, return FAIL to the previous decision.

04Formulas and why they hold

unit: |{ℓ ∈ C : ℓ unassigned}| = 1 and no ℓ ∈ C true

one open literal left in an unsatisfied clause

The clause is false unless that literal is true, so setting it is forced, not a choice, and costs no branching.

empty: every ℓ ∈ C false

the conflict test

A clause is a disjunction; if all its literals are false the clause is false, and assignments only ever add more false literals deeper in the tree.

leaves ≤ 2^(number of decisions)

propagation shrinks the tree

Only decisions branch; forced assignments follow without a choice, so the more propagation, the fewer decisions on any path.

05Why it works, and when it does not

Where hill climbing from 0000 stops at 1000 (h 5), backtracking cannot be fooled by a local maximum: it either reaches an assignment satisfying every clause or has tried all possibilities. Related CSP pages: Backtracking (csp-backtracking) is the plain version of this search, Forward checking (csp-forward-checking) is what unit propagation does after each assignment, and Arc consistency (csp-ac3) generalises it by propagating until nothing more can be removed.

07Traps

  • See the pieces separately on the example sat-implication-chain: clauses 1–3 give a chain of unit propagations (a, b, c) with no decision, g is a pure literal, the decision d = T runs into an empty clause (backtrack) and d = F succeeds. Value order F first removes the backtrack; pure literal 'No' makes g a unit propagation instead. sat-unsat shows the UNSAT proof: every branch ends in an empty clause.
  • A conflict means undo to the last decision; forced assignments are not retried with the other value.
  • Unassigned variables at the end are free, not False: the printed bit string fills them with 0 only for display.
  • Pure literals and unit propagation never lose solutions, but without them the same formula needs more backtracks.
  • An 'UNSAT' answer is a proof (all branches closed), whereas local search failing to find a solution proves nothing.
