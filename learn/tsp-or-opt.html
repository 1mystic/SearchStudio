Or-opt (move a city)

Run it step by step

Perturbative methods start from a complete tour and improve it by small changes. Or-opt is one such change: move one city to another place in the tour. Repeating the best improving change until none helps is hill climbing, and where it stops is a local optimum.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

MoveGen(Or-opt) lists every tour reachable by one Or-opt move (about n² neighbours). Steepest-descent hill climbing moves to the best neighbour while it is strictly better than the current tour.

02Pseudocode

node ← start tour
loop
    neighbours ← MoveGen(node)          # remove a city, reinsert it elsewhere
    best ← cheapest neighbour
    if cost(best) ≥ cost(node): return node   (local optimum)
    node ← best

03Line by line

node ← start tourUsually a constructive tour (Greedy, NN) or a random one.
neighbours ← MoveGen(node)All tours one Or-opt move away: about n² of them.
best ← cheapest neighbourTies: the alphabetically smaller tour.
if cost(best) ≥ cost(node): return nodeNo neighbour is strictly better: a local optimum for this neighbourhood.
node ← bestMove and repeat.

04Formulas and why they hold

Δ = C(p,q) − C(p,c) − C(c,q) + C(x,c) + C(c,y) − C(x,y)

take c out from between p and q, put it between x and y

Moving one city removes three edges and adds three, so Or-opt moves are a subset of 3-edge exchanges.

05Why it works, and when it does not

Hill climbing is fast and always improves until it stops, but it stops at the first tour with no better neighbour. A denser neighbourhood has fewer such traps but costs more per step.

06Properties

completeno
optimalno (local optimum)
timeabout n² evaluations per step
spaceO(n)

07Traps

  • Hill climbing stops when no neighbour is strictly better, even if equal-cost neighbours exist (a plateau).
  • A different move set has different local optima: on Six cities from the Greedy tour (238) Or-opt reaches the optimum 224, where 2-opt and 2-city exchange both stop at 229.
  • Count neighbours with the right formula for the operator.
  • In an asymmetric TSP a 2-edge move reverses a block, so many edge costs change.
