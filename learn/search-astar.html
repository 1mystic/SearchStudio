A*

Run it step by step

A* combines the cost already paid with an estimate of the cost remaining. With an estimate that never overestimates, it finds the cheapest path and usually expands far fewer nodes than Uniform Cost Search.

01Definition

A state-space search problem has a start node S, a goal test, and a MoveGen function that lists the neighbours of a node. The search keeps two lists: OPEN (nodes generated but not yet expanded) and CLOSED (nodes already expanded). Each entry is a node pair (node, parent, value) so the path can be read back through parents. OPEN is ordered by f(N) = g(N) + w·h(N). With w = 1 and an admissible h this is A*; with w > 1 it is weighted A*.

02Pseudocode

OPEN ← [(S, nil, g=0)] ordered by f = g + w·h
while OPEN not empty
    N ← node with least f;  remove it
    if GoalTest(N): return the path
    move N to CLOSED
    for each child C with g' = g(N) + k(N,C)
        new: add to OPEN
        cheaper than its pair on OPEN/CLOSED: update parent and g (reopen if CLOSED)

03Line by line

f(N) = g(N) + h(N)Estimated cost of the cheapest solution through N.
N ← least-f node
if GoalTest(N): returnWith admissible h the first goal picked is optimal.
update cheaper pathsChange parent and g; reopen CLOSED nodes if needed.

04Formulas and why they hold

f(N) = g(N) + h(N)

paid so far plus estimated remainder

Balances progress (g) against promise (h).

admissible: h(N) ≤ h*(N) for all N

never overestimate the true remaining cost

Then f never overestimates the true cost of a path through N, so the optimal path is never skipped.

consistent: h(N) ≤ k(N,M) + h(M)

the triangle inequality for h

Then f never decreases along a path and closed nodes never need reopening.

weighted A*: f = g + w·h, w > 1

trust the heuristic more

Faster, but the path can be up to w times the optimum.

05Why it works, and when it does not

A* is optimal with an admissible h and is as efficient as any algorithm using the same h. Overestimating h (inadmissible) can make it return a worse path: try the 'inadmissible' example.

07Traps

  • Admissible ≠ consistent: consistency implies admissibility, not the reverse.
  • h = 0 makes A* behave like UCS.
  • With an inadmissible h the first goal found may not be optimal.
