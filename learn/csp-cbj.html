Week 12 · Constraint processing · lookback

Conflict-directed backjumping

Run it step by step

Chronological backtracking returns to the previous variable even when that variable has nothing to do with the failure. Conflict-directed backjumping is a look-back method: it analyses the failure and jumps back to the variable that is actually responsible.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Each variable Xᵢ carries a conflict set conf(Xᵢ): the earlier variables whose current values rejected some value of Xᵢ. When Xᵢ has no value left, jump to the deepest variable h in conf(Xᵢ), unassign everything in between, merge conf(Xᵢ) − {h} into conf(h), and let h try its next value.

02Pseudocode

CBJ(i):                                  # variables X₁…Xₙ in a fixed order
    conf(Xᵢ) ← { }
    for each value a in D(Xᵢ)
        if a clashes with an assigned Xⱼ (j < i): add Xⱼ to conf(Xᵢ); try next value
        else assign Xᵢ = a; r ← CBJ(i + 1); if r = success: return success
             if r jumps to h < i: unassign Xᵢ; return r        # Xᵢ is skipped
    h ← deepest variable in conf(Xᵢ)         # no value left
    conf(h) ← conf(h) ∪ conf(Xᵢ) − {h}
    return jump to h

03Line by line

try a value of Xᵢ
clash with an earlier XⱼRecord Xⱼ in conf(Xᵢ): it is a culprit.
no value leftDead end for Xᵢ.
jump to the deepest variable in conf(Xᵢ)Variables between h and Xᵢ are skipped: changing them cannot repair the failure.
merge the conflict setsh inherits the other culprits, so that if h fails too the jump is still correct.

04Formulas and why they hold

h = max { j : Xⱼ ∈ conf(Xᵢ) }

the jump target is the latest culprit

Every value of Xᵢ clashes with something in conf(Xᵢ); changing a variable outside it cannot help, and the latest culprit is the nearest place where a change might help.

conf(h) ← conf(h) ∪ conf(Xᵢ) − {h}

pass the blame on

If h fails after its other values are tried, the earlier culprits of Xᵢ are also culprits for h.

05Why it works, and when it does not

Finds exactly the same first solution as chronological backtracking, with the same orders, in fewer or equal nodes: jumping over a variable never skips a solution.

06Properties

completeyes
optimaln/a
timeO(dⁿ) worst case, ≤ backtracking
spaceO(n²) for conflict sets

07Traps

  • Try example 'Backjumping' (D fails because of A alone): CBJ jumps from D over B and C to A, 10 values tried against 24 for chronological backtracking. On example 'Thrashing' it needs 16 against 45, but forward checking (6) still beats it: CBJ is look-back, it reacts only after the failure.
  • A jump over a level is only possible when the failing variable has no conflict with the intermediate variables.
  • Conflict sets are only extended by the variables that clashed, not by every earlier variable.
  • The culprit recorded for each value here is the first clashing variable in the ordering (the usual Prosser formulation); other books record all of them. Both are sound; the choice of culprit is **supplementary** to the lecture.
