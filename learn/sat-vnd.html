Variable Neighbourhood Descent (N1 → N1–n)

Run it step by step

A local maximum depends on the neighbourhood: a state can have no better one-flip neighbour and still have a better string two flips away. VND uses that. It searches the small, cheap neighbourhood first and only widens it when it is stuck.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Let Nk be the strings that differ from the current one in exactly k bits, so |Nk| = C(n,k), and let N1–k = N1 ∪ … ∪ Nk. Start with k = 1. Move to the best member of N1–k if it is strictly better, and reset k to 1. Otherwise increase k. When k passes n, the state is a local maximum of every neighbourhood, hence a global maximum of h (N1–n is the whole space).

02Pseudocode

N ← start;  k ← 1
while k ≤ n and h(N) < m
    nbrs ← all strings that differ from N in at most k bits     # N1–k
    B ← the neighbour with the largest h (ties: fewest flips, then lowest bit)
    if h(B) > h(N): N ← B;  k ← 1
    else: k ← k + 1
return N

03Line by line

N ← start; k ← 1Begin with the smallest neighbourhood.
nbrs ← N1–k of NSizes are C(n,1), C(n,1)+C(n,2), …; the last one covers all 2ⁿ − 1 other strings.
B ← best neighbourTies: fewer flips first, then lowest bit.
if h(B) > h(N): N ← B, k ← 1Success: return to the cheap neighbourhood.
else k ← k + 1Failure: pay for a bigger neighbourhood.

04Formulas and why they hold

|Nk| = C(n,k)

choose which k of the n bits to flip

This is why the neighbourhoods grow so fast: for n = 4 the sizes are 4, 6, 4, 1.

|N1–k| = C(n,1) + … + C(n,k)

cumulative size

|N1–n| = 2ⁿ − 1, so the last phase is brute force: VND ends exactly at a global maximum, at brute-force cost in the worst case.

05Why it works, and when it does not

On the course example, hill climbing stops at 1000 (h 5), but flipping the pair b, d reaches 1101 (h 6), a solution. VND finds it by widening to N1–2 at 1000. Most of the time the cheap neighbourhood does the work and the expensive ones are only paid for when needed. The same escape works at a strict local maximum: on 'Local-maximum trap' (sat-local-trap) N1 fails at 0100 (all four neighbours have h 6) and N1–2 flips c and d to reach the solution 0111. The first step lists the sizes C(n,k): 4, 6, 4, 1 for four variables, 6, 15, 20, 15, 6, 1 for the six-variable sat-random-3sat; set the largest neighbourhood to 1 to see plain hill climbing fail.

06Properties

completeyes if run up to N1–n (it then covers the space)
optimalyes with N1–n
timeup to O(2ⁿ · m)
spaceO(n)

07Traps

  • After an improvement return to N1, not to the neighbourhood that found it.
  • N1–2 contains the one-flip neighbours as well as the pairs: 4 + 6 = 10 strings for n = 4, not 6.
  • If the whole sequence fails the result is a true global maximum of h, but a global maximum with h < m means the formula is unsatisfiable.
