Best First on a state space

Run it step by step

Best First Search trusts the heuristic completely. In the 8-puzzle, h counts tiles out of place or their Manhattan distance to the goal squares; the board that looks nearest to the goal is expanded first.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

OPEN holds node pairs (state, parent, h) ordered by h. The goal test is on picking from OPEN, ties break alphabetically (by state), and a state already on OPEN or CLOSED is not added again. Unlike A*, the cost already paid is ignored.

02Pseudocode

OPEN ← [(S, nil, h(S))];  CLOSED ← [ ]
while OPEN not empty
    N ← the pair with the least h;  remove it      # ties: alphabetical
    if GoalTest(N): return the path
    CLOSED ← N : CLOSED
    children ← MoveGen(N) minus states on OPEN or CLOSED
    OPEN ← OPEN ++ children, sorted by h

03Line by line

04Formulas and why they hold

tiles out of place: h₁ = number of tiles not on their goal square

blank not counted

Each such tile needs at least one move.

Manhattan: h₂ = Σ |row − goal row| + |col − goal col|

sum of tile distances

A tile moves one square per move, so it needs at least its Manhattan distance; h₂ ≥ h₁.

05Why it works, and when it does not

Both heuristics are admissible for the 8-puzzle, but Best First ignores g, so it may take a long way round. Compare the length of its solution with A*'s on the same board.

06Properties

completeyes on a finite space with CLOSED
optimalno
timeexponential worst case
spaceexponential worst case

07Traps

  • Best First is not optimal even with an admissible h: on example space-8-puzzle-12 it returns a 44-move solution with tiles out of place (the shortest has 12). With Manhattan distance it happens to find 12 moves there, which is luck, not a guarantee.
  • A heuristic that is 0 everywhere turns the order into ties, i.e. alphabetical order of states.
  • For water jugs there is no useful h (it is 0); for missionaries and cannibals the studio uses the full-boat crossing bound.
