Iterated hill climbing

Run it step by step

If one hill climb gets stuck, start again from somewhere else. Iterated hill climbing repeats hill climbing from random starting tours and keeps the best local optimum found.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Repeat r times: generate a random tour, hill climb to a local optimum, remember it if it is the best so far.

02Pseudocode

best ← none
repeat r times
    N ← random tour
    N ← HillClimbing(N)
    if N better than best: best ← N
return best

03Line by line

repeat r times
N ← random tourExploration: a fresh starting point.
N ← HillClimbing(N)Exploitation: climb to the local optimum of that basin.
keep the best

04Formulas and why they hold

P(success) ≈ 1 − (1 − p)^r

with r restarts, each landing in the optimum's basin with probability p

More restarts make it more likely that at least one starts in the right basin.

05Why it works, and when it does not

Simple and effective when local optima are many but hill climbing is cheap. It wastes effort if most random starts lead to the same poor basin.

06Properties

completeno
optimalno
timer × hill climb
spaceO(n)

07Traps

  • Each restart is independent: nothing is learned between restarts.
  • Random starts are usually much worse than constructive tours.
