Week 3 · TSP · local search

Best neighbour, k moves

Run it step by step

Hill climbing stops when no neighbour is better. A tempting fix is to keep going: always move to the best neighbour, even if it is worse. With no memory, this does not escape for long. From a local optimum the best neighbour is worse, but from there the best neighbour is usually the local optimum again, so the search bounces back and forth.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Repeat a fixed number k of times: generate all neighbours of the current tour with the chosen MoveGen and move to the cheapest one (ties alphabetically by tour). There is no test for improvement and no memory of visited tours.

02Pseudocode

N ← start;  bestSeen ← N
repeat k moves
    N ← the best neighbour of N          # lowest cost, even if worse than N
    if N better than bestSeen: bestSeen ← N
    if N was visited before: report the cycle
return bestSeen

03Line by line

N ← best neighbour of NThe best neighbour is taken even if it is more expensive than N.
track bestSeenThe current tour may get worse, so remember the best tour met on the way.
N visited before → cycleThe move is deterministic: once a tour repeats, the same sequence repeats for ever.

04Formulas and why they hold

cycle length = move now − move when this tour was first visited

how many moves until the tour returns

A deterministic rule applied to a state we already visited must reproduce the same path again.

05Why it works, and when it does not

It shows why local search needs more than a greedy best-neighbour rule: tabu search adds a memory (forbidden moves) and simulated annealing adds randomness precisely to break this cycle.

07Traps

  • Reporting the final tour instead of the best tour seen.
  • Thinking that moving uphill alone is enough to escape a local optimum: without memory or randomness it goes straight back. On Six cities the walk bounces between 224 and 229 for ever (a cycle of length 2 from move 1), exactly the repetition that tabu search's memory forbids.
