Week 2 · Graph search · uninformed

BFS on a state space

Run it step by step

Water jugs, the 8-puzzle and missionaries-and-cannibals all have a start state, a goal test and a rule for the legal moves. Nobody draws their graph: MoveGen writes the neighbours of a state when asked. Breadth First Search explores in rings, so the first goal it picks is a solution with the fewest moves.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

A state-space problem is (S, GoalTest, MoveGen). OPEN holds node pairs (state, parent, depth) that have been generated but not expanded; CLOSED holds those already expanded. BFS keeps OPEN as a queue. The goal test is applied when a node is picked from OPEN. A child that is already on OPEN or CLOSED is not added again, which is what makes this graph search rather than tree search. The parent in each pair lets us read the solution back.

02Pseudocode

OPEN ← [(S, nil, 0)];  CLOSED ← [ ]
while OPEN not empty
    (N, parent, d) ← head(OPEN);  remove it
    if GoalTest(N): return the path via parent pointers
    CLOSED ← (N, parent, d) : CLOSED
    children ← MoveGen(N) minus states on OPEN or CLOSED
    OPEN ← OPEN ++ [(C, N, d+1) for C in children]     # append = queue
return failure

03Line by line

OPEN ← [(S, nil, 0)]The start state has no parent.
(N, parent, d) ← head(OPEN)Oldest pair first (queue), so shallow states go before deep ones.
if GoalTest(N): return pathTested on picking, not on generating.
children ← MoveGen(N) minus seen statesDiscard states already on OPEN or CLOSED.
OPEN ← OPEN ++ childrenAppend: new states wait behind older ones.

04Formulas and why they hold

nodes ≤ 1 + b + b² + … + b^d

at most b^d states in the last ring

Every state in ring k has up to b children, so rings grow geometrically; CLOSED stops repeats from adding more.

solution length = depth of the first goal picked

fewest moves

All states at depth k are picked before any at depth k + 1.

05Why it works, and when it does not

The water-jug problem (8, 5, 3 litres, aim for 4) has only 16 reachable states, so BFS finishes quickly and the answer, 7 pourings, is the shortest. On the 8-puzzle the rings grow fast, which is why informed search (A*) matters.

06Properties

completeyes (finite state space)
optimalyes, fewest moves (unit move cost)
timeO(b^d)
spaceO(b^d)

07Traps

  • Without CLOSED the same state is generated again and again (pour A→B then B→A). Graph search cuts these cycles.
  • The goal test is on picking from OPEN, not on generating, so the last ring is generated before the search stops.
  • BFS needs memory for a whole ring: on example space-8-puzzle-12 (a 12-move board) it hits the 400-expansion cap long before the goal, while A* with Manhattan distance needs 16 expansions.
  • Ties and the order of children follow MoveGen's order. A different order gives a different but equally short solution.
