Week 4 · TSP · genetic

Representation lab

Run it step by step

A genetic algorithm needs a way to write a tour as a string it can cut and recombine. The same tour can be written as the path (visit order), as an adjacency list (who follows whom) or as an ordinal string (index into a shrinking list). Each representation allows different crossover operators and has different pitfalls.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Path: the cities in visiting order. Adjacency: entry i is the city that follows the i-th city (alphabetical order) in the tour. Ordinal: with a reference list of the tour's cities in alphabetical order, gene 1 is the position of the first tour city in that list; delete it; gene 2 is the position of the second tour city in the remaining list; and so on.

02Pseudocode

Ordinal encode:  ref ← the cities of the tour in alphabetical order
    for each city c of the tour, in order:  gene ← position of c in ref (1-based);  delete c from ref
Ordinal decode:  ref ← same list;  for each gene g: city ← g-th city of ref;  delete it from ref
Adjacency encode: a[c] ← the city after c in the tour (cyclic), listed in alphabetical order of c
Adjacency decode: start at the first city, repeatedly go to a[current]; valid iff all n cities are visited before returning
Crossover: cut two ordinal strings after k genes and swap the tails; decode both children

03Line by line

ref ← cities in alphabetical orderThe reference list fixes what 'position k' means. The notes' ordinal example (I,L,G,D,F,H,J,E,K,M → 6,8,4,1,2,2,2,1,1,1) is reproduced by the alphabetical list D,E,F,G,H,I,J,K,L,M of the cities in the tour.
gene ← position of c in ref; delete cDeleting the city makes the list shrink, so gene i is always between 1 and n−i+1.
adjacency a[c] ← city after cListed in alphabetical order of c. The notes' example J,G,F,I,L,M,E,D,H,K gives H,D,I,F,K,L,G,J,M,E.
adjacency of the reversed tourEvery arrow flips, so the list is the inverse mapping; it is also a valid single cycle with the same cost.
cut two ordinal strings and swap tailsGene i of any child is still in 1..n−i+1, so it always selects an existing city when decoding: the child is a tour.

04Formulas and why they hold

gene i ∈ {1, …, n−i+1}

the i-th gene indexes a list that already lost i−1 cities

Mixing the first genes of one string with the later genes of another never leaves this range, so decoding cannot fail.

a[c] = successor of c

adjacency stores edges, directed along the tour

A list is a tour only if following a[ ] from any city visits all n cities before returning; two or more separate cycles are legal lists but not tours.

a_reverse = a⁻¹

the reversed tour's adjacency is the inverse permutation

A tour and its reverse are the same cycle with the same cost, so both lists are valid representations.

05Why it works, and when it does not

Ordinal representation is the course's example of a representation chosen so that a plain one-point crossover is legal. The price is that gene positions mean different things depending on earlier genes, so a child can look unlike either parent.

06Properties

completen/a
optimaln/a
timeO(n²)
spaceO(n)

07Traps

  • The reference list is the tour's own cities in alphabetical order, not the order of the tour.
  • Genes count from 1, and the list shrinks after every deletion.
  • Adjacency is read in alphabetical order of the city, not along the tour.
  • A valid-looking adjacency list can break into sub-cycles; check that it is one cycle through every city.
