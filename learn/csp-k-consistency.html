Week 11 · Constraint processing

Strong k-consistency check (k ≤ 3)

Run it step by step

Node, arc and path consistency are the first three members of one family. A network is i-consistent when every consistent assignment to any i − 1 variables can be extended to any i-th variable. It is strongly k-consistent when it is i-consistent for every i ≤ k. This page checks the definition literally and shows each assignment that fails to extend. **Supplementary:** the course introduces 2- and 3-consistency; the general definition and the idea of strong k-consistency (Freuder) go slightly beyond it.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Level i = 1: every variable has a non-empty domain (there are no unary constraints in this problem type). Level i = 2: every value of every variable has a supporting value in every other variable (arc consistency). Level i = 3: every consistent pair (X = a, Y = b) can be extended to every third variable Z (path consistency). A failing assignment A with variable V means that no value of V is compatible with A: for i = 2 it implies deleting the value, for i = 3 it implies the nogood {X = a, Y = b}, i.e. the pair is forbidden, which acts as a new constraint between X and Y.

02Pseudocode

for j = 1 .. k
    for each set S of j − 1 variables and each consistent assignment A to S
        for each variable V not in S
            if no value v in D(V) makes A ∪ {V = v} consistent: report (A, V) as a failure
    if there is no failure: the network is j-consistent
strongly k-consistent  ⇔  j-consistent for every j ≤ k

03Line by line

choose j − 1 variables and a consistent assignmentOnly assignments that violate no constraint among themselves count.
choose another variable VThe assignment must extend to V.
look for a value of V compatible with the assignmentIf none exists, the assignment is a failure.
implication of a failurei = 2: delete the value. i = 3: record the nogood on the pair.

04Formulas and why they hold

i-consistent ⇔ ∀ S, |S| = i − 1, ∀ consistent A on S, ∀ V ∉ S, ∃ v ∈ D(V): A ∪ {V = v} consistent

every consistent partial solution of size i − 1 can grow by one more variable

A solution restricted to any i − 1 variables is a consistent assignment, and it extends to every other variable; an assignment that cannot extend is therefore in no solution and can be forbidden without losing solutions.

strongly k-consistent ⇔ j-consistent for all j ≤ k

all the lower levels hold too

Strong k-consistency on a network of k variables lets a solution be built without backtracking (Freuder); mere k-consistency without the lower levels guarantees nothing.

05Why it works, and when it does not

The two-colour triangle is 2-consistent (arc consistency finds nothing) but not 3-consistent: the pair (X = a, Y = b) cannot be extended to Z, which is exactly how path consistency proves there is no solution. The ordering chain X < Y < Z is not even 2-consistent until arc consistency has reduced it; afterwards it is strongly 3-consistent.

06Properties

completeno (a test, not a solver)
optimaln/a
timeO(n^k · d^k)
spaceO(n)

07Traps

  • Strong k-consistency needs every level up to k; a network can be 3-consistent and not 2-consistent.
  • Only consistent assignments count: a pair that already violates a constraint is not a failure.
  • k-consistency for small k does not make search backtrack-free unless k reaches the width-related bound; it only removes some dead ends.
