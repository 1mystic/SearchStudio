Best neighbour, fixed moves

Run it step by step

Hill climbing quits when no neighbour is better. A simple escape is to keep moving anyway: take the best neighbour even if it is worse or equal, for a fixed number of moves, and remember the best string seen. The trouble is that the best neighbour of a state is often the state we just left.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

At each of the k moves, evaluate the N1 neighbours of the current string, move to the one with the highest h (ties to the lowest bit) regardless of whether h improves, and update the best string seen. Return the best string seen.

02Pseudocode

N ← start;  bestSeen ← N
repeat for a fixed number of moves
    B ← the N1 neighbour with the largest h (ties: lowest bit)
    N ← B                                   # even if h(B) ≤ h(N)
    if h(N) > h(bestSeen): bestSeen ← N
return bestSeen

03Line by line

B ← best N1 neighbourThe same choice as hill climbing.
N ← B even if not betterThis is what lets the walk leave a local maximum.
update bestSeenThe walk may go down, so the final string is not necessarily the best.
stop after the fixed number of movesOr earlier when a solution is reached, if asked.

04Formulas and why they hold

the best neighbour, uphill or not

Flipping a variable back and forth keeps being the best choice, so the walk can cycle: x → y → x → y …

05Why it works, and when it does not

It shows why memory is needed. From the solution 1101 on the course example the best neighbour is 0101 (h 5) and from there the best neighbour is 1101 again: a cycle of length 2. Tabu search forbids the move back for a few iterations to break such cycles. The cycle also appears while still unsolved: on 'Local-maximum trap' (sat-local-trap) the walk goes 0000 → 0100 (h 7) → 1100 (h 6, downhill) → 0100 → 1100 … and never reaches the solutions 0011 or 0111, because 0100 is always the best neighbour of 1100.

07Traps

  • The last string is not the answer; the best string seen is.
  • A revisited string means a cycle: from then on the walk repeats forever.
  • With a solution reached the walk would normally stop; turn the stop off to watch the cycling.
