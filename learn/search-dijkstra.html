Dijkstra's Algorithm

Run it step by step

Dijkstra's algorithm is Uniform Cost Search written as a table. Each node carries a best-known distance d. The WHITE node with the smallest d is made BLACK, and then its neighbours are checked to see whether going through it gives them a shorter distance.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Colour every node WHITE and give it d = ∞, except the start with d = 0. Pick the WHITE node N with least d and colour it BLACK: its d is now the true shortest distance from the start. For each WHITE neighbour C of N with edge cost k, if d(N)+k < d(C) then set d(C) = d(N)+k and parent(C) = N (a relaxation). Stop when the goal is coloured BLACK, then follow the parents back to the start.

02Pseudocode

d(S) ← 0;  d(v) ← ∞ for the rest;  all nodes WHITE
repeat
    N ← WHITE node with least d(N)           # ties: alphabetical
    colour N BLACK
    if N = goal: return the path (follow parents)
    for each WHITE neighbour C of N with edge cost k:
        if d(N) + k < d(C):                  # relaxation
            d(C) ← d(N) + k;  parent(C) ← N
until no WHITE node has d < ∞              # goal unreachable

03Line by line

d(S) = 0, all nodes WHITENothing is final yet.
pick the WHITE node with least dTies go alphabetically. A pick is counted each time a node turns BLACK.
colour it BLACKIts distance can no longer improve, because every other WHITE node has d at least as large and costs are not negative.
relax its WHITE neighboursReplace d(C) when going through N is shorter, and record N as the parent.
stop when the goal is BLACKRead the path through the parents.

04Formulas and why they hold

d(N) + k(N,C) < d(C) ⇒ d(C) ← d(N) + k(N,C)

relaxation

A shorter way to C through the newly final node N has been found, so C's estimate improves.

pick argmin d over WHITE nodes

closest unfinished node

With non-negative costs no later path can reach it more cheaply, so it can be made BLACK.

05Why it works, and when it does not

It gives the shortest path to every node it blackens, and to the goal once the goal is picked. It is the same search as UCS: OPEN is the set of WHITE nodes with finite d, CLOSED is the BLACK set. It has no sense of direction, so it spreads in all directions.

06Properties

completeyes (finite graph)
optimalyes (non-negative costs)
timeO(V²) or O(E log V)
spaceO(V)

07Traps

  • Only WHITE neighbours are relaxed: a BLACK node is already final.
  • Edge costs must not be negative; with negative edges a BLACK node could still improve.
  • d of a node can change several times before it turns BLACK (for example G falling from 9 to 8): only the BLACK value is final.
  • Count picks, not relaxations.
