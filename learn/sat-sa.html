Simulated annealing

Run it step by step

Simulated annealing borrows from metalworking: hot metal moves freely, then settles as it cools. The search accepts worse moves often while the temperature is high and becomes stricter as it cools, so it explores first and exploits later.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Pick a random one-flip neighbour X of N. Compute ΔE = h(X) − h(N) (positive means X satisfies more clauses) and move with probability P = 1/(1 + e^(−ΔE/T)). After every step lower T according to the cooling schedule. Return the best string seen.

02Pseudocode

N ← start;  bestSeen ← N;  T ← T0
repeat k times
    X ← N with a random bit flipped
    ΔE ← h(X) − h(N)                  # positive = improvement (we maximise h)
    P ← 1 / (1 + e^(−ΔE / T))
    if random u < P: N ← X
    if h(N) > h(bestSeen): bestSeen ← N
    T ← next temperature (geometric: α·T, or linear down to Tend)
return bestSeen

03Line by line

X ← N with a random bit flippedRandom, not best: annealing samples the neighbourhood.
ΔE ← h(X) − h(N)Positive = improvement because SAT maximises h.
P ← 1 / (1 + e^(−ΔE/T))The course's sigmoid acceptance rule.
if u < P: N ← Xu is the random number shown in the trace.
T ← α·TGeometric cooling with α slightly below 1; a linear schedule is offered as well.

04Formulas and why they hold

P = 1 / (1 + e^(−ΔE/T))

a sigmoid of ΔE scaled by temperature

ΔE > 0 gives P > ½, ΔE < 0 gives P < ½; larger |ΔE|/T pushes P toward 1 or 0.

T → ∞: P → ½; T → 0: P → 1 if ΔE > 0, 0 if ΔE < 0

hot = coin flip, cold = hill climbing

Temperature sets the balance between exploration and exploitation.

Tₖ = T₀ · αᵏ

geometric cooling after k steps

Slow cooling (α close to 1) leaves more time to escape local maxima.

Tₖ = T₀ − k · (T₀ − Tend)/steps

linear cooling

**Supplementary**: an alternative schedule, not in the course notes; it reaches Tend exactly at the last step.

05Why it works, and when it does not

Accepting some worse moves lets the search leave a local maximum such as 1000 (h 5) and cooling makes it settle near a good string. With the sigmoid rule even an improving move can be rejected, so always keep bestSeen. Compare with the random walk, which ignores h: on sat-ten-var (10 variables, 3 solutions among 1024) 30 steps solve it for 51 of 100 seeds with annealing and 7 of 100 with the random walk; seed 2 shows it (annealing solves it, the walk reaches only h 46 of 48). Raise T0 a lot and annealing degrades towards the random walk, lower it and it behaves like hill climbing.

07Traps

  • ΔE sign: for SAT it is h(new) − h(current), the reverse of the TSP cost version.
  • At finite T an improving move is still rejected with probability 1 − P.
  • Return bestSeen: the current string may wander off the best one.
  • Results depend on the seed; the same seed repeats the run exactly.
