Week 11 · Constraint processing

Arc consistency (AC-1, AC-3)

Run it step by step

A constraint satisfaction problem has variables, each with a domain of values, and constraints saying which combinations are allowed. A solution assigns every variable a value from its domain so that every constraint holds. Arc consistency removes values that cannot possibly be part of any solution, before or during search.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

An arc (X, Y) is consistent if every value of X has some supporting value in Y. Revise(X, Y) deletes unsupported values. AC-1 revises every arc until a whole pass changes nothing; AC-3 keeps a queue and re-examines only arcs pointing into a variable whose domain just shrank.

02Pseudocode

Revise(X, Y):
    for each a in D(X): if no b in D(Y) satisfies the constraint: delete a from D(X)
    return whether D(X) changed

AC-3:
    Q ← every arc (X, Y)
    while Q not empty
        (X, Y) ← pop(Q)
        if Revise(X, Y): add every arc (Z, X) with Z ≠ Y to Q
AC-1: repeat Revise on all arcs until a full pass changes nothing

03Line by line

queue all arcsBoth directions of every constraint.
Revise(X, Y)Delete values of X with no support in Y.
if D(X) shrank: queue (Z, X)Neighbours of X may have lost their support.
queue empty → arc consistentEmpty domain: no solution. All singletons: solved.

04Formulas and why they hold

a ∈ D(X) survives ⇔ ∃ b ∈ D(Y): (a, b) ∈ C(X, Y)

a value needs a partner on every arc

A value with no partner can never satisfy that constraint, so it can be deleted safely.

AC-3: O(e · d³)

each arc is re-queued at most d times, each revision costs d²

Domains only shrink, so the work is bounded.

05Why it works, and when it does not

Cheap reasoning that shrinks domains; sometimes it solves the problem outright (the chain example), sometimes it only prunes (map colouring).

06Properties

completeno (filtering only)
optimaln/a
timeO(e·d³)
spaceO(e)

07Traps

  • Arcs are directed: (X, Y) and (Y, X) are different.
  • Arc consistency does not guarantee a solution exists.
