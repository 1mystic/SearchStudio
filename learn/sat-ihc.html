Week 4 · SAT · stochastic

Iterated hill climbing

Run it step by step

One hill climb ends at the first local maximum it meets, and which one it meets depends on where it started. Iterated hill climbing runs the same N1 hill climb from several starting assignments and keeps the best. It is the simplest way of adding randomness to local search.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Choose r starting bit strings (random, or listed explicitly). From each run strict N1 hill climbing (best one-flip neighbour, ties to the lowest bit, move only if h strictly increases). Remember the string with the largest h. Stop early if some run reaches h = m.

02Pseudocode

best ← none
for each start S (given, or r random bit strings)
    N ← HillClimbing_N1(S)
    if h(N) > h(best): best ← N
    if h(best) = m: stop (solved)
return best

03Line by line

for each start SStarts come from the 'starts' parameter if it is filled in, otherwise from the seeded random generator, so a run can be repeated exactly.
N ← HillClimbing_N1(S)Exactly the deterministic hill climbing of week 3, run to its end.
if h(N) > h(best): best ← NOnly strictly better results replace the best; ties keep the earlier one.
stop when h = mA solution cannot be improved, so further restarts are pointless.

04Formulas and why they hold

P(at least one start reaches the solution) = 1 − (1 − q)^r

q = fraction of starts whose hill climb ends at the solution

Starts are independent, so all r fail with probability (1 − q)^r. **Supplementary** (not in the course notes).

05Why it works, and when it does not

On the four-variable course example hill climbing from 0000 stops at 1000 (h 5). Among five starts only 0101 climbs on to 1101 (h 6). More starts means more chances, but each start is a fresh gamble: nothing learned in one run is used in the next.

completeno

07Traps

  • Restarts are independent: iterated hill climbing does not remember where earlier runs failed.
  • Two different starts can end in the same local maximum, so r starts do not give r different answers (on sat-four-var the starts 1110 and 0010 both climb to 1010).
  • Failing on all r starts does not prove the formula unsatisfiable.
