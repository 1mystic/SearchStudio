Week 5 · Graph search · optimal

British Museum (brute force on paths)

Run it step by step

The British Museum method looks at every possible path, one by one, and keeps the cheapest. It needs no cleverness and no heuristic, and its answer is the optimum. Its cost is the number of paths, which explodes as the graph grows.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Enumerate all simple paths (no repeated node) from S to the goal by depth-first exploration, in alphabetical order of neighbours. Each time a path reaches the goal, compare its cost with the best so far and keep the cheaper (the earlier one is kept on a tie). The answer has the same cost as Uniform Cost Search. The tracer shows each complete path found; after the first 40 it only reports improvements, and it counts everything.

02Pseudocode

best ← none;  cost* ← ∞
DFS over simple paths from S (a node may not repeat on the current path):
    if the path ends at the goal:
        if cost(path) < cost*: best ← path;  cost* ← cost(path)
        (do not extend a path past the goal)
return best

03Line by line

extend the path one neighbour at a timeA node already on the path is skipped, so every path is simple.
when the goal is reached, record the pathDo not extend past the goal.
keep the cheapest so farStrictly cheaper replaces; ties keep the first.
backtrack and continueUntil every path has been tried.

04Formulas and why they hold

cost(path) = Σ k(edge)

sum of edge costs

Paths are compared by total cost.

answer = min over all simple S→goal paths

exhaustive minimum

Nothing is skipped, so the minimum is the true optimum.

05Why it works, and when it does not

It shows how much work the intelligent methods avoid. Uniform Cost Search finds the same cost while looking at a tiny fraction of the paths.

06Properties

completeyes
optimalyes
timeexponential (number of simple paths)
spaceO(path length)

07Traps

  • The number of simple paths can be exponential in the number of nodes.
  • It must not reuse a node on the same path, otherwise cycles give infinitely many paths.
  • Finding the first path is not enough: all paths must be tried.
