Week 7 · Game playing

Dominant strategies and Nash equilibria (supplementary)

Run it step by step

Supplementary material: this topic is not in the course notes but is the natural next step from minimax. In minimax one player's gain is the other's loss. In a general two-player game both players choose at the same time and the payoffs need not add up to zero. A Nash equilibrium is a pair of choices from which neither player gains by changing alone. The Prisoner's Dilemma shows the surprise: the only equilibrium can be worse for both than another outcome.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

A strategy s is strictly dominated by t if t gives a strictly higher payoff than s against every strategy of the opponent; a rational player never plays a dominated strategy, so it can be removed (and the removal can make more strategies dominated: iterated elimination). A pair (r, c) is a pure Nash equilibrium if r is a best response to c and c is a best response to r. An outcome is Pareto-dominated if some other outcome is at least as good for both players and strictly better for one.

02Pseudocode

repeat: remove a strictly dominated strategy of either player
        (s is dominated by t if t pays more than s against EVERY remaining opponent strategy)
until nothing can be removed
for each column: mark the row player's best payoff;  for each row: mark the column player's best payoff
pure Nash equilibrium = a cell with both payoffs marked
equilibrium is Pareto-inefficient if another cell pays both players at least as much and one strictly more

03Line by line

remove a strictly dominated strategyCompare two strategies of the same player against every opponent strategy still in the game.
repeat on the smaller gameRemoving a strategy can make others dominated that were not before.
mark each player's best responsesFor each column the row player's best payoff, for each row the column player's best payoff.
cells with both payoffs marked are pure Nash equilibriaNobody gains by switching alone.
check each equilibrium for a Pareto improvementIs there a cell that is at least as good for both and better for one?

04Formulas and why they hold

s is strictly dominated by t ⇔ u(t, o) > u(s, o) for every opponent strategy o

t beats s whatever the other player does

If this holds, s can never be the right choice, so it can be ignored without changing the outcome.

(r*, c*) is a pure Nash equilibrium ⇔ u₁(r*, c*) ≥ u₁(r, c*) for all r and u₂(r*, c*) ≥ u₂(r*, c) for all c

each choice is a best response to the other

No player can improve by deviating alone, so the pair is stable.

05Why it works, and when it does not

It shows what rational play looks like when both sides move at once, and that individually rational choices can be collectively bad (the Prisoner's Dilemma), which is why rules, contracts and repetition matter.

06Properties

completefinds every pure equilibrium
optimalno (equilibrium is not optimal)
timeO(r·c·(r + c))
spaceO(r·c)

07Traps

  • Dominance must be strict and against every opponent strategy; being better against most of them is not enough.
  • Equilibrium does not mean best: the equilibrium of the Prisoner's Dilemma is worse for both players than mutual cooperation.
  • A game can have several pure equilibria (Battle of the Sexes) or none (Matching Pennies). Without a pure equilibrium, players must randomise: a mixed equilibrium always exists (Nash's theorem), but this tool finds only pure ones.
  • Payoffs are written (row player, column player). Read the first number for the row player.
