Week 7 · Game playing

SSS*

Run it step by step

SSS* treats game-tree search as best-first search over strategies. It keeps an OPEN list of node triples and always refines the most promising one, so it never looks at a leaf that alpha-beta would skip, and sometimes skips leaves alpha-beta looks at.

01Definition

OPEN holds triples (node, status, merit) where status is LIVE (not yet examined) or SOLVED. Starting from (root, LIVE, +∞), repeatedly take the triple with the highest merit and apply one of the six cases until the root is SOLVED; its merit is the minimax value.

02Pseudocode

OPEN ← [(root, LIVE, +∞)]
loop
    (J, s, h) ← triple with the highest merit (ties: leftmost)
    if J = root and s = SOLVED: return h
    if s = LIVE:
        leaf      → insert (J, SOLVED, min(h, e(J)))
        MAX node  → insert (C, LIVE, h) for every child C
        MIN node  → insert (first child, LIVE, h)
    if s = SOLVED:
        J's parent is MAX → insert (parent, SOLVED, h); purge every other descendant of the parent
        J's parent is MIN → next sibling exists: insert (sibling, LIVE, h)
                            else insert (parent, SOLVED, h)

03Line by line

LIVE leafSolve it with merit min(h, e(leaf)).
LIVE MAX nodeAdd all children as LIVE with the same merit.
LIVE MIN nodeAdd only the first child: a MIN node is refined one child at a time.
SOLVED node with MAX parentIt is the MAX parent's best alternative (highest merit first), so the parent is solved; purge the parent's other descendants.
SOLVED node with MIN parentMIN's replies must all be examined: add the next sibling as LIVE, or solve the parent if this was the last child.

04Formulas and why they hold

merit h = upper bound on the value of the best strategy through the node

how good this line could still be for MAX

Taking the highest merit first is best-first search; the first solved root has the true value.

05Why it works, and when it does not

Dominates alpha-beta in leaves evaluated, at the cost of an OPEN list that can grow large.

06Properties

07Traps

  • Ties in merit are broken by leftmost position.
  • When a MAX parent is solved, remove all its other descendants from OPEN.
