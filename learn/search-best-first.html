Best First Search

Run it step by step

Best First Search uses a heuristic h(N), a guess of the distance from N to the goal, and always expands the node that looks closest to the goal.

01Definition

A state-space search problem has a start node S, a goal test, and a MoveGen function that lists the neighbours of a node. The search keeps two lists: OPEN (nodes generated but not yet expanded) and CLOSED (nodes already expanded). Each entry is a node pair (node, parent, value) so the path can be read back through parents. OPEN is ordered by h(N).

02Pseudocode

OPEN ← [(S, nil, h(S))] ordered by h
while OPEN not empty
    N ← node with least h;  remove it
    if GoalTest(N): return the path
    move N to CLOSED
    add children not on OPEN or CLOSED, ordered by h

Often reaches the goal quickly, but is not optimal and can be misled by a poor heuristic.
