Random walk

Run it step by step

A random walk is the opposite extreme of hill climbing: it ignores costs entirely and steps to a random neighbour each time. It is a baseline that shows how much the evaluation function helps.

01Definition

From the current tour move to a uniformly random neighbour; record the best tour seen.

02Pseudocode

N ← start;  bestSeen ← N
repeat k times
    N ← random neighbour of N
    if N better than bestSeen: bestSeen ← N
return bestSeen

03Line by line

N ← start
N ← random neighbour of NNo comparison with the current cost.
update bestSeenThe only use of the cost function.

04Formulas and why they hold

P(next = X) = 1 / |N(current)|

every neighbour is equally likely

No bias toward better tours, so the walk drifts toward wherever most tours are: mostly bad ones.

05Why it works, and when it does not

Pure exploration can in principle reach anything, but without guidance it rarely finds good tours in reasonable time.
