Stochastic hill climbing

Run it step by step

Ordinary hill climbing only ever accepts improvements and so gets stuck at the first local optimum. Stochastic hill climbing keeps the 'look at one random neighbour' step but accepts it with a probability that depends on how much better or worse it is, so it can sometimes walk downhill and escape.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

At a fixed temperature T, move from N to a random neighbour X with probability P = 1/(1 + e^(−ΔE/T)), where ΔE = cost(N) − cost(X) (positive means X is shorter). Unlike simulated annealing, T never changes.

02Pseudocode

N ← start;  bestSeen ← N
repeat k times
    X ← random neighbour of N
    ΔE ← cost(N) − cost(X)            # positive = improvement
    P ← 1 / (1 + e^(−ΔE / T))         # T is fixed
    if random u < P: N ← X
    if N better than bestSeen: bestSeen ← N
return bestSeen

03Line by line

X ← random neighbour of NOne random neighbour is examined, not the whole neighbourhood.
ΔE ← cost(N) − cost(X)Positive ΔE is an improvement because the TSP minimises cost.
P ← 1 / (1 + e^(−ΔE/T))The sigmoid: ΔE = 0 gives exactly ½; larger |ΔE| pushes P towards 1 or 0.
if u < P: N ← Xu is a uniform random number in [0,1), drawn from the seeded generator.

04Formulas and why they hold

P = 1 / (1 + e^(−ΔE/T))

sigmoid of ΔE/T

ΔE > 0 gives P > ½, ΔE < 0 gives P < ½, ΔE = 0 gives P = ½ whatever T is.

T large: P → ½; T small: P → 1 (ΔE>0) or 0 (ΔE<0)

hot is a coin flip, cold is hill climbing

T scales ΔE: dividing by a big T squashes all differences; a small T amplifies them.

05Why it works, and when it does not

A fixed T is a fixed compromise: too hot and the search wanders at random, too cold and it behaves like plain hill climbing and stalls in a local optimum. Annealing resolves this by lowering T over time.

07Traps

  • ΔE is cost(current) − cost(next): improvement positive, the opposite of some textbooks.
  • Even an improving move is only accepted with probability P < 1 at finite T, so keep the best tour seen.
  • The same seed gives the same run; change the seed, not the code, to see a different one.
