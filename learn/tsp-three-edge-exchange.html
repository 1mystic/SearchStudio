3-edge exchange

Run it step by step

Perturbative methods start from a complete tour and improve it by small changes. 3-edge exchange is one such change: remove three edges and reconnect the segments. Repeating the best improving change until none helps is hill climbing, and where it stops is a local optimum.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

MoveGen(3-edge exchange) lists every tour reachable by one 3-edge exchange move (O(n³) neighbours). Steepest-descent hill climbing moves to the best neighbour while it is strictly better than the current tour.

02Pseudocode

node ← start tour
loop
    neighbours ← MoveGen(node)          # remove three edges, reconnect segments
    best ← cheapest neighbour
    if cost(best) ≥ cost(node): return node   (local optimum)
    node ← best

03Line by line

node ← start tourUsually a constructive tour (Greedy, NN) or a random one.
neighbours ← MoveGen(node)All tours one 3-edge exchange move away: O(n³) of them.
best ← cheapest neighbourTies: the alphabetically smaller tour.
if cost(best) ≥ cost(node): return nodeNo neighbour is strictly better: a local optimum for this neighbourhood.
node ← bestMove and repeat.

04Formulas and why they hold

|N₃e| = O(n³)

choose three edges, then a reconnection

Denser than 2-edge exchange: fewer local optima, more work per step.

05Why it works, and when it does not

Hill climbing is fast and always improves until it stops, but it stops at the first tour with no better neighbour. A denser neighbourhood has fewer such traps but costs more per step.

07Traps

  • Hill climbing stops when no neighbour is strictly better, even if equal-cost neighbours exist (a plateau).
  • Count neighbours with the right formula for the operator.
  • In an asymmetric TSP a 2-edge move reverses a block, so many edge costs change.
