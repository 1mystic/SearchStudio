Hill climbing (N1)

Run it step by step

Local search treats the assignments as states and a flip of one variable as a move. The heuristic h counts satisfied clauses, so a solution is a state with h = m. Hill climbing walks uphill on h and never accepts a step that does not strictly improve it.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

The neighbourhood N1 of a bit string is the n strings that differ from it in exactly one bit. Pick the neighbour with the highest h (ties go to the lowest bit, i.e. the alphabetically first variable). Move only if its h is strictly greater than the current h; otherwise stop.

02Pseudocode

N ← start
loop
    if h(N) = m: return N                      # solved
    nbrs ← all strings obtained by flipping one bit of N     # N1
    B ← the neighbour with the largest h (ties: lowest bit)
    if h(B) > h(N): N ← B
    else: return N                             # local maximum or plateau

03Line by line

N ← startA bit string, one bit per variable.
if h(N) = m: return NGoal test: all clauses are satisfied.
nbrs ← flip one bit of NThe N1 neighbourhood has exactly n members.
B ← best neighbourTies broken by the lowest bit index: flipping a is tried before b, and so on.
if h(B) > h(N): N ← B else stopStrict improvement. A neighbour with equal h is a sideways move that hill climbing refuses, so it stops on a plateau.

04Formulas and why they hold

|N1| = C(n,1) = n

n neighbours per state

Each iteration costs n evaluations of h.

move iff h(B) > h(N)

strictly better only

This rule is what makes the method stop on plateaus; tabu search and simulated annealing relax it.

05Why it works, and when it does not

It is cheap and often gets close, but a state whose neighbours are all no better is a trap even when h < m. On the course example it climbs 0000 (h 4) → 1000 (h 5) and stops, although 1101 (h 6) is a solution two flips away.

07Traps

  • Stopping with h < m does not mean the formula is unsatisfiable, only that this start is stuck.
  • Equal h is not an improvement: a plateau stops strict hill climbing.
  • Ties between equally good neighbours go to the lowest bit; a different rule can give a different path.
  • Two different traps: on a plateau some neighbour has equal h, at a strict local maximum every neighbour is worse. The captions say which one. Course example sat-four-var stops on a plateau (1000: three neighbours with h 5); the example 'Local-maximum trap' (sat-local-trap) stops at 0100, where all four neighbours have h 6.
