Greedy heuristic

Run it step by step

The Greedy heuristic builds the tour out of the shortest edges available anywhere on the map, like snapping together the closest pairs of cities first. Two rules keep the pieces from becoming something other than one big loop.

01Definition

Sort all edges by length. Accept an edge unless it would give a city a third edge (degree 3) or close a loop before all cities are included (premature cycle). Stop at n edges.

02Pseudocode

sort all edges by length (ties: alphabetical)
for each edge (a,b)
    if degree(a) = 2 or degree(b) = 2: reject
    if a, b already connected and fewer than n−1 edges chosen: reject (premature cycle)
    else accept
read the tour from the chosen edges, starting at the given city

03Line by line

sort all edges by lengthThere are n(n−1)/2 edges; ties are broken alphabetically.
if degree(a) = 2 or degree(b) = 2: rejectIn a tour every city has exactly two neighbours.
if a and b are already connected: rejectAdding the edge would close a cycle that misses some cities. Only the very last edge may close the cycle.
else acceptThe edge joins two fragments or extends one.
read the tour from a cityThe edge set does not depend on any city; the start only fixes how the path representation is written.

04Formulas and why they hold

accept (a,b) ⇔ deg(a) < 2 ∧ deg(b) < 2 ∧ (find(a) ≠ find(b) ∨ |E| = n−1)

both ends have a free slot, and they are in different fragments unless this is the closing edge

These are exactly the conditions for the chosen edges to still be part of some Hamiltonian cycle.

cost = Σ of accepted edge lengths

the tour cost is just the accepted edges

Greedy accepts exactly n edges.

05Why it works, and when it does not

Short edges are likely to belong to good tours, so Greedy usually beats Nearest Neighbour. But fragments are joined late, and the final edges are whatever remains legal, which can be very long.

06Properties

completealways returns a tour
optimalno
timeO(n² log n)
spaceO(n²)

07Traps

  • Track degrees and fragments carefully; most exam errors are an illegal acceptance.
  • The last accepted edge is forced and may be long.
  • 'Greedy from city X' only changes where you start writing the tour.
