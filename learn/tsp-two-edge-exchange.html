2-edge exchange (2-opt)

Run it step by step

Perturbative methods start from a complete tour and improve it by small changes. 2-edge exchange is one such change: remove two non-adjacent edges and reconnect. Repeating the best improving change until none helps is hill climbing, and where it stops is a local optimum.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

MoveGen(2-edge exchange) lists every tour reachable by one 2-edge exchange move (n(n−3)/2 neighbours). Steepest-descent hill climbing moves to the best neighbour while it is strictly better than the current tour.

02Pseudocode

node ← start tour
loop
    neighbours ← MoveGen(node)          # remove (a,b),(c,d); add (a,c),(b,d); reverse the block
    best ← cheapest neighbour
    if cost(best) ≥ cost(node): return node   (local optimum)
    node ← best

03Line by line

node ← start tourUsually a constructive tour (Greedy, NN) or a random one.
neighbours ← MoveGen(node)All tours one 2-edge exchange move away: n(n−3)/2 of them.
best ← cheapest neighbourTies: the alphabetically smaller tour.
if cost(best) ≥ cost(node): return nodeNo neighbour is strictly better: a local optimum for this neighbourhood.
node ← bestMove and repeat.

04Formulas and why they hold

|N₂e| = n(n−3)/2

pairs of edges that do not share a city

Each of n edges can pair with n−3 non-adjacent edges; each pair is counted twice.

Δ = C(a,c) + C(b,d) − C(a,b) − C(c,d)

new edges minus removed edges

Only four edges change, so a move is evaluated in O(1) without recomputing the whole tour.

05Why it works, and when it does not

Hill climbing is fast and always improves until it stops, but it stops at the first tour with no better neighbour. A denser neighbourhood has fewer such traps but costs more per step.

06Properties

completeno

07Traps

  • Hill climbing stops when no neighbour is strictly better, even if equal-cost neighbours exist (a plateau).
  • Count neighbours with the right formula for the operator.
  • In an asymmetric TSP a 2-edge move reverses a block, so many edge costs change.
