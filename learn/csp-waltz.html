Week 11 · Constraint processing

Waltz algorithm

Run it step by step

How do we see 3D shapes in a line drawing? Waltz showed that each junction of lines allows only a few physical interpretations, and that neighbouring junctions must agree. Propagating that agreement usually leaves a single interpretation.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Lines get labels: + (convex edge), − (concave edge) or an arrow (occluding boundary, object on the right). Each junction type (L, fork, arrow, T) has a catalogue of allowed labellings (6, 5, 3, 4: the Huffman–Clowes catalogue). Waltz filtering is arc consistency between junctions that share a line.

02Pseudocode

for each junction J: D(J) ← catalogue labellings for J's type (L 6, fork 5, arrow 3, T 4)
if the background is known: keep only labellings with outer lines as arrows (object on the right)
Q ← every pair of junctions sharing a line
while Q not empty
    (J, K) ← pop(Q)
    delete from D(J) every labelling whose label on line J–K no labelling in D(K) agrees with
    if D(J) shrank: push (I, J) for every other neighbour I of J
labels agree: + with +, − with −, an arrow leaving J with the same arrow entering K

03Line by line

classify junctions by geometryTwo lines: L. Three: fork (all angles < 180°), arrow (one angle > 180°), T (two lines collinear).
start with full catalogues
background constraintOuter boundary lines are arrows going clockwise around the object.
propagateDelete labellings that no labelling at the other end of a line agrees with.

04Formulas and why they hold

18 junction labellings: L 6, fork 5, arrow 3, T 4

the Huffman–Clowes catalogue for trihedral scenes

Only these arise from corners where three planes meet, viewed generically.

agree(+,+), agree(−,−), agree(→ leaving J, → entering K)

a line has one label seen from both ends

This is the binary constraint propagated between junctions.

05Why it works, and when it does not

Constraint propagation instead of search: the cube drawing becomes unambiguous once the background is fixed. Without that, several interpretations survive.

07Traps

  • Arrow labels are relative to direction: 'out' at one end is 'in' at the other.
  • Arc consistency can leave several labellings; a search step picks among them.
