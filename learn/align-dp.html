Week 6 · Sequence alignment

Sequence alignment (dynamic programming)

Run it step by step

Comparing two DNA strings means lining them up with as few mismatches and gaps as possible. Every alignment is a path through a grid, so the best alignment is a shortest path, and dynamic programming finds it by filling a table.

01Definition

D(i,j) is the cheapest alignment of the first i letters of a with the first j letters of b. Fill the table from D(0,0) = 0 using three moves: diagonal (pair two letters), down (a letter of a against a gap), right (a letter of b against a gap). Trace back from D(m,n).

02Pseudocode

D(0,0) ← 0;  D(i,0) ← i·gap;  D(0,j) ← j·gap
for i ← 1..m, for j ← 1..n
    D(i,j) ← min( D(i−1,j−1) + cost(aᵢ, bⱼ),     # diagonal: match or mismatch
                  D(i−1,j)   + gap,               # down: aᵢ against a gap
                  D(i,j−1)   + gap )              # right: bⱼ against a gap
trace back from (m,n) choosing a move that produced each value

03Line by line

D(i,0) = i·gap, D(0,j) = j·gapAligning a prefix against nothing costs only gaps.
D(i,j) = min of three movesDiagonal, down or right, each adding its cost.
trace back from (m,n)Follow the move that produced each value to read the alignment.

04Formulas and why they hold

D(i,j) = min{ D(i−1,j−1) + c(aᵢ,bⱼ), D(i−1,j) + gap, D(i,j−1) + gap }

best of: pair the letters, gap in b, gap in a

Every alignment of the prefixes ends in exactly one of these three ways, so the minimum over them is optimal (optimal substructure).

05Why it works, and when it does not

Exact and O(m·n). The same lattice can be searched by A* with an admissible heuristic, or with frontier ideas to cut memory, which is how the course connects alignment to search.

06Properties

completeyes
optimalyes
timeO(m·n)
spaceO(m·n)

07Traps

  • Costs are minimised here; scoring versions maximise similarity instead.
  • Off-by-one: row i refers to letter aᵢ, i.e. a[i−1] in code.
