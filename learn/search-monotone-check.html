Admissibility & monotone check

Run it step by step

A* is only as good as its heuristic. Two properties matter: admissibility (never overestimate the remaining cost) and the monotone or consistency condition (the estimate never drops by more than the cost of an edge). This tool checks both on any graph.

01Definition

Compute the true remaining cost h*(n) to the goal by Dijkstra's algorithm from the goal. h is admissible if h(n) ≤ h*(n) everywhere. h is monotone if h(m) ≤ k(m,n) + h(n) for every edge (m,n).

02Pseudocode

h* ← Dijkstra from the goal (true cost to the goal)
for each node n: admissible at n  ⇔  h(n) ≤ h*(n)
for each edge (m, n) with cost k: monotone  ⇔  h(m) ≤ k + h(n)   (both directions if undirected)
monotone everywhere and h(goal) = 0  ⇒  admissible

03Line by line

h* by Dijkstra from the goalExact distances, so the check is exact.
check h(n) ≤ h*(n) for each nodeAdmissibility makes A* optimal.
check h(m) ≤ k(m,n) + h(n) for each edgeMonotonicity makes f non-decreasing along every path.

04Formulas and why they hold

admissible: h(n) ≤ h*(n)

never overestimate

A* then never discards the optimal path.

monotone: h(m) − h(n) ≤ k(m,n)

the estimate drops by at most the edge cost

Then f(n) = g(n) + h(n) ≥ g(m) + h(m) = f(m): f never decreases, so a node is closed with its optimal g and never reopened.

monotone ∧ h(goal) = 0 ⇒ admissible

consistency is the stronger property

Summing the edge inequalities along the optimal path gives h(n) ≤ h*(n).

05Why it works, and when it does not

Knowing which property holds tells you whether A* is optimal (admissible) and whether it may need to reopen closed nodes (not monotone).
