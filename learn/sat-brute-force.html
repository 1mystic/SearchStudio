Week 3 · SAT · exact

Brute force (truth table)

Run it step by step

A SAT instance asks for an assignment of true or false to every variable that makes every clause true. With n variables there are 2ⁿ assignments, so the most direct method is to try them all. This is the baseline against which the local-search methods of this week are measured.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Treat the assignment as a bit string (bit i = 1 means variable i is true). Enumerate every bit string, evaluate every clause, and record h = the number of satisfied clauses. A string with h = m satisfies the formula.

02Pseudocode

for each bit string X of length n, in counting order 00…0, 00…1, …
    h(X) ← number of clauses satisfied by X
    if h(X) = m: X is a solution
return the solutions (or, if none, the rows with the largest h)

03Line by line

for each bit string X in counting order0000, 0001, 0010, … with the first variable as the leftmost bit.
h(X) ← clauses satisfied by XA clause is satisfied when at least one of its literals is true.
if h(X) = m: X is a solutionEvery clause true. Keep going: there may be more than one solution.
return the solutionsIf the table has no h = m row, the formula is unsatisfiable and the largest h is the best we can do.

04Formulas and why they hold

|search space| = 2ⁿ

two choices per variable

This is why n is limited to 6 here: 2⁶ = 64 rows still fit on a screen; 2²⁰ is already a million.

h(X) = Σᵢ [clauseᵢ satisfied by X]

the heuristic is the number of true clauses

The same h guides every local-search method in this section; local search tries to climb to h = m without enumerating the table.

05Why it works, and when it does not

Brute force is complete and exact, which makes it the reference answer: every local-search result can be checked against its truth table. Its cost is the reason local search exists.

06Properties

completeyes
optimalyes (finds every solution)
timeO(2ⁿ · m)
spaceO(n)

07Traps

  • A solution is h = m (all clauses), not just a high h.
  • There can be several solutions, or none; do not stop at the first unless asked.
  • The truth table grows as 2ⁿ: adding one variable doubles it.
  • No row with h = m proves the formula unsatisfiable: on sat-unsat the best rows have h = 4 of 5 clauses, and brute force can say 'none' for certain. Local search failing says nothing of the kind.
