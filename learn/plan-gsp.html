Week 8 · Planning

Goal Stack Planning

Run it step by step

A planning problem gives an initial state, a goal and operators described in STRIPS form: each operator has preconditions, an add list and a delete list. In the blocks world the operators are pickup, putdown, stack and unstack, and AE means the arm is empty. Goal Stack Planning, the strategy of STRIPS, works through the goals one at a time using a stack.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Push the conjunctive goal and its parts. Pop goals that hold. Replace an unsatisfied goal with an operator that achieves it and that operator's preconditions. When an operator reaches the top, apply it and add it to the plan. Re-check conjunctions, because later actions can undo earlier goals.

02Pseudocode

push the conjunct goal, then each goal in it
while the stack is not empty
    x ← top
    if x is a goal that holds in the state: pop
    elif x is an unsatisfied goal: push an action O that achieves it, then O's preconditions (conjunct and each)
    elif x is a conjunct: if all hold pop, else push its unsatisfied goals again
    elif x is an action: pop, apply it to the state, append it to the plan

03Line by line

push conjunct and each goalThe order of the goals matters.
goal holds → pop
goal fails → push operator + preconditionsHeuristic choice: stack for on, unstack the block on top for clear, and so on.
operator on top → apply, recordIts preconditions were just achieved.
conjunct broken → push its goals againThis is where the Sussman anomaly costs extra steps.

04Formulas and why they hold

linear planning: solve g₁, then g₂, … in order

one goal at a time

Fine for independent goals; interacting goals (Sussman anomaly) make it undo its own work.

05Why it works, and when it does not

Fast and easy to trace, but not optimal and sensitive to goal order: on the Sussman anomaly it needs 10 steps where 6 suffice.

07Traps

  • Push preconditions so that the one to achieve first is on top.
  • Always re-check the conjunct goal after its parts are popped.
