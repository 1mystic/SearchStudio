Week 6 · Graph search · space saving

Frontier Search

Run it step by step

In A* the CLOSED list does two jobs: it stops the search regenerating nodes it has already expanded, and it lets us rebuild the path. Frontier search replaces the first job with a few bits on each OPEN node, and drops CLOSED entirely. This is in the course's discussion of memory-saving search (frontier search and its divide and conquer version); the used-operator bits are shown here in their simplest form, so treat the exact bookkeeping as **supplementary**.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Each OPEN node stores the set of neighbours that have already been expanded and generated it (its used operators). When N is expanded it never generates a child in used(N). Children already on OPEN merge: the new parent is added to their used set and the cheaper g is kept. After expansion N is discarded. Because no expanded node is stored, the search returns the cost; the path needs a relay recursion (see Divide and Conquer Frontier Search).

02Pseudocode

OPEN ← [(S, g=0, used={})]                 # no CLOSED list
while OPEN not empty
    N ← node with least f;  remove it
    if GoalTest(N): return its cost
    for each child C of N with g' = g(N) + k(N,C), if C is not in used(N):
        if C is on OPEN: used(C) ← used(C) ∪ {N};  if g' is lower, update g(C)
        else add (C, g', used = {N}) to OPEN
    (N itself is forgotten)

03Line by line

N ← least f; goal testSame as A*.
skip children in used(N)Those are expanded nodes; this replaces the CLOSED check.
child on OPEN: add N to its used setSo that the child will not regenerate N later.
forget NOnly the frontier remains in memory.

04Formulas and why they hold

memory = |OPEN|

there is no CLOSED list

In grid-like graphs the frontier is a thin front, much smaller than everything expanded so far.

h consistent (h(N) ≤ k(N,M) + h(M))

needed for correctness

Then a node is expanded with its final g, so never needing to be reopened. Reversible moves (undirected graph) are also needed, so the used bit can be set.

05Why it works, and when it does not

A* minus its biggest list: on the 4×5 grid it holds at most 5 nodes in total where A* holds 20 (19 of them CLOSED). It trades away the path: on its own it can only report the cost, and DCFS or DC-BFHS recover the path.

07Traps

  • With an inconsistent heuristic a node may need reopening, which frontier search cannot do: on 'Admissible but not monotone h: A* reopens C' it returns S–C–G = 6 although the optimum is 5 (A* reopens C and finds S–A–B–C–G).
  • Only for undirected graphs here: a directed edge has no 'reverse operator' to mark as used.
  • To print the path this tracer carries the path along with each OPEN node. That is for the display only and is not counted in the memory figures.
