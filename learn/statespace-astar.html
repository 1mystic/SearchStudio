Week 5 · Graph search · informed

A* on a state space

Run it step by step

A* adds the cost paid so far to the heuristic estimate of what remains. On the 8-puzzle, with h = tiles out of place or Manhattan distance, it finds a shortest solution while expanding far fewer boards than breadth-first search.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Node pairs are (state, parent, g) with f = g + h. Every move costs 1, so g is the depth along the current best path. OPEN is ordered by f with alphabetical ties, the goal test is on picking, and a cheaper path to a known state updates its parent. If h never overestimates the true remaining moves (admissible) the first goal picked is optimal.

02Pseudocode

OPEN ← [(S, nil, g=0)] ordered by f = g + h
while OPEN not empty
    N ← the pair with the least f;  remove it       # ties: alphabetical
    if GoalTest(N): return the path
    CLOSED ← N : CLOSED
    for each child C of MoveGen(N) with g' = g(N) + 1
        new: add (C, N, g') to OPEN
        cheaper than its pair on OPEN or CLOSED: update parent and g (reopen if CLOSED)

03Line by line

N ← least-f pair on OPENf = g + h.
if GoalTest(N): return pathWith admissible h this is a shortest solution.
children: g' = g(N) + 1Unit cost per move.

04Formulas and why they hold

f(N) = g(N) + h(N)

paid plus estimated remainder

An estimate of the cheapest solution through N.

h₁ ≤ h₂ ≤ h*

tiles out of place ≤ Manhattan ≤ true moves left

Each misplaced tile needs ≥ 1 move and each needs ≥ its Manhattan distance, so both are admissible and h₂ dominates h₁: A* with h₂ expands no more states than with h₁.

missionaries: h = 2·⌈(n − k)/(k − 1)⌉ + 1

n people on the left bank, boat holds k (**supplementary**)

Each round trip moves at most k − 1 people across net, and the last trip moves k; ignoring the safety rule only lowers the bound, so it is admissible.

05Why it works, and when it does not

A better (larger, still admissible) h prunes more of the search. Run example space-8-puzzle-12 with each heuristic and compare the 'expanded' count: both return the same 12-move solution, Manhattan after 16 expansions, tiles out of place after 79, and h = 0 does not finish within the 400-expansion cap. (On the easy five-move board space-8-puzzle the two tie at 6.)

07Traps

  • Admissible is not enough to compare: the larger of two admissible heuristics is better informed.
  • The blank is never counted in either heuristic; counting it can overestimate.
  • With h = 0 (water jugs have no good h) A* degenerates to Uniform Cost Search, here the same as BFS.
