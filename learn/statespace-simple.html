Simple search (no node pairs)

Run it step by step

The first search procedures in the course keep only states on OPEN. They answer 'is a goal reachable?' but not 'how do I get there?'. This tracer runs that version on a state space so you can see the answer arrive without a path.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

OPEN is a list of states, CLOSED a list of states. Each loop picks the head of OPEN, tests it, moves it to CLOSED and adds its unseen children. Nothing records which state generated which, so when the goal is picked there is no chain of parents to follow. Replacing each state by a node pair (state, parent, depth) fixes that.

02Pseudocode

OPEN ← [S];  CLOSED ← [ ]
while OPEN not empty
    N ← head(OPEN);  remove it
    if GoalTest(N): return "goal reached"        # but by which moves?
    CLOSED ← N : CLOSED
    children ← MoveGen(N) minus states on OPEN or CLOSED
    OPEN ← OPEN ++ children  (queue)  or  children ++ OPEN  (stack)
return failure

03Line by line

N ← head(OPEN)A queue gives BFS order, a stack gives DFS order.
if GoalTest(N): returnReached, but only the fact is known.
CLOSED ← N : CLOSEDRemember N is expanded.
children ← MoveGen(N) minus seenWithout CLOSED, cycles can loop forever.

04Formulas and why they hold

path recovery needs one pointer per state

parent(N)

The path is the chain goal, parent(goal), parent(parent(goal)), … back to the start; with no pointers there is no chain.

05Why it works, and when it does not

This is the motivation for node pairs: one extra field per entry turns 'a goal exists' into 'here is a solution'.

06Properties

completeyes (finite space, with CLOSED)
optimaln/a: no path is returned
timeas BFS / DFS
spaceas BFS / DFS

07Traps

  • Reaching the goal is not the same as having the solution. For puzzles the moves are the answer: run this on space-water-jug and the last step says the path is lost, while BFS on the same problem prints the 7 pourings.
  • Switching OPEN between queue and stack changes how many states are expanded (15 for the queue, 9 for the stack on space-water-jug) but never recovers the path.
  • Without CLOSED (not offered here) the procedure may never stop on a cyclic state space.
