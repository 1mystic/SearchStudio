Simulated annealing

Run it step by step

Simulated annealing borrows from metalworking: hot metal moves freely, then settles into a strong structure as it cools. The search accepts worse moves often while the 'temperature' is high, and becomes stricter as it cools.

01Definition

Pick a random neighbour X of the current tour N. Compute ΔE = cost(N) − cost(X) (positive means X is better) and move with probability P = 1/(1 + e^(−ΔE/T)). Lower T after each step.

02Pseudocode

N ← start;  bestSeen ← N;  T ← T0
repeat k times
    X ← random neighbour of N
    ΔE ← cost(N) − cost(X)            # positive = improvement
    P ← 1 / (1 + e^(−ΔE / T))
    if random u < P: N ← X
    if N better than bestSeen: bestSeen ← N
    T ← α · T
return bestSeen

03Line by line

X ← random neighbour of NRandom, not best: SA samples the neighbourhood.
ΔE ← cost(N) − cost(X)Positive ΔE = improvement (TSP minimises cost).
P ← 1 / (1 + e^(−ΔE/T))The course's sigmoid acceptance rule.
if u < P: N ← Xu is a uniform random number in [0,1).
T ← α·TGeometric cooling, α slightly below 1.

04Formulas and why they hold

P = 1 / (1 + e^(−ΔE/T))

a sigmoid of ΔE scaled by temperature

ΔE > 0 gives P > ½, ΔE < 0 gives P < ½; larger |ΔE| pushes P toward 1 or 0.

T → ∞: P → ½; T → 0: P → 1 if ΔE > 0, 0 if ΔE < 0

hot = coin flip, cold = hill climbing

Temperature controls the balance between exploration and exploitation.

Tₖ = T₀ · αᵏ

temperature after k steps

Slow cooling (α close to 1) gives more time to escape local optima.

05Why it works, and when it does not

Accepting some worse moves lets SA leave local optima; cooling makes it settle. With this sigmoid rule even a better move can be rejected (P < 1), so always keep the best tour seen.

06Properties

completeno
optimalonly with impractically slow cooling
timek samples
spaceO(n)

07Traps

  • ΔE sign: define it so that positive means better for the problem at hand.
  • With the sigmoid rule, P(better move) < 1 at finite T.
  • Return bestSeen: the current tour can wander off the best one.
