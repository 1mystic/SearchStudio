Hill climbing in the blocks world (h1 vs h2)

Run it step by step

Here a state is a set of stacks and a move takes the top block of one stack and puts it on the table or on top of another stack. The heuristic is only as good as the information it holds: h1 looks at each block's immediate support, h2 looks at the entire structure beneath it. Same search, same moves, different heuristic: one gets stuck, the other solves the problem.

⎙Tip: press Ctrl+P to print or save this page as PDF.

01Definition

Steepest-ascent hill climbing: move to the best neighbour as long as it is strictly better than the current state. h1 gives +1 to a block that sits on the right thing (the table for a bottom block) and −1 otherwise. h2 gives a block +k when it and the k−1 blocks below it all stand on the right things, and −k (its height in the stack) otherwise. The goal scores n under h1 and n(n+1)/2 for a single tower under h2. (The exact course picture is not reproduced here; this is the standard construction of the example.)

02Pseudocode

N ← start
loop
    pick the neighbour M (move one top block to the table or onto another stack) with the highest h(M)
    if h(M) ≤ h(N): return N      // local maximum or plateau: stuck
    N ← M
    if N is the goal: return N

h1(N) = Σ over blocks: +1 if on the thing it should be on in the goal, −1 otherwise
h2(N) = Σ over blocks: +k if its whole structure of k blocks (down to the table) is right, −k otherwise

03Line by line

start from the initial stateScore it with the chosen heuristic.
generate every neighbourMove the top block of any stack to the table or onto any other stack. Ties are broken alphabetically by move name.
pick the best neighbourSteepest ascent: highest h wins.
if it is not strictly better, stopA local maximum (or plateau): hill climbing cannot see past it.
otherwise move and repeatStop when the goal is reached.

04Formulas and why they hold

h1 = Σ ±1 per block, + if on the right thing

count blocks that are locally right

Cheap, but a block resting on a wrongly built tower still scores +1, so dismantling that tower looks like a loss.

h2 = Σ ±k per block, + if its whole support structure is correct

credit a correct structure of k blocks with k, penalise a wrong one with k

A wrongly placed block pulls down everything above it, so dismantling a wrong tower is rewarded and building a right one is rewarded more with height.

05Why it works, and when it does not

The same algorithm with a different evaluation function turns failure into success: the quality of the heuristic decides whether a hill-climber can find the goal.

07Traps

  • A block that is on the right thing is not necessarily correct: if what it stands on is wrong, h2 counts it as wrong.
  • Stuck does not mean the goal is unreachable: it means no single move improves h.
  • The goal is read from on(x,y) and ontable(x) facts; a block with no fact is assumed to belong on the table.
